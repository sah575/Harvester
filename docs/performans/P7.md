# P7 — genel yerel efekt havuzu

Kullanıcının son talimatıyla **enkaz katmanı, collider, uyutma ve enkaz havuzuna bağlama kısmı yapılmadı; beklemede**. Önceki geçici collider uygulaması kullanıcının isteğini karşılamadı. Bu adım bu sorunu çözmüş sayılmaz.

`Harvester.Race.Pool.Prewarm(prefab, adet)`, `Spawn(prefab, konum, dönüş, ebeveyn)` ve `Release(nesne)` yerel efektler için hazırdır. `IPoolable.OnPoolSpawn/OnPoolRelease` tüketicinin durum sıfırlama kancalarıdır. `PooledObject.ReleaseAfter(sn)` zamanlı iadeyi sağlar. Havuz ilk kullanıma kadar GameObject/Update oluşturmaz. Etkin nesne yarış sahnesine aittir; boşlar sahneler arası havuzda saklanır. Çift iade kuyruğu çoğaltmaz, ölçek/hız sıfırlanır, parçacıklar temizlenir. Ağ objeleri bu API ile spawn edilmez; mevcut oyunda ağ efekt tüketicisi olmadığı için NGO instance handler eklenmedi.

Play mode denetimi: ön ısıtma, aynı örneği yeniden kullanma, çift iade, Rigidbody hızı/ölçek sıfırlama, zamanlı iade, sahne sahipliği, Clear sonrası etkin nesne iadesi geçti. Derleme/Console hatasız.

Editör mikro ölçümü (10.000 döngü, basit Rigidbody prototipi): havuz **77,73 ms / 0 B** yönetilen tahsis; Instantiate + DestroyImmediate **87,10 ms / 0 B**. Bu basit ve editöre özgü ölçüm gerçek yarış FPS kazanımı değildir; native tahsisler bu B sayısına dahil değildir. Havuz henüz yarışta tüketilmediği için kare süresi iyileştirmesi iddia edilmiyor. Gelecekte mermi/roket/kıvılcım tüketicileri kendi durumlarını IPoolable ile sıfırlayıp ayrıca ölçülmelidir.

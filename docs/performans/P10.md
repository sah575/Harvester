# P10 — build ve grafik API karşılaştırması

14 Kasım 2026. Mono korundu; URP 17'nin etkin `URPShaderStrippingSetting.stripUnusedPostProcessingVariants` değeri Unity API ile true doğrulandı. Üç uyumluluk/etkin serileştirme alanı aynı değere getirildi. `Harvester/Apply Build Optimizations` bunu yeniden uygular. Kullanılmayan post işlem varyantları ayıklanınca Linux development build 257,62 → 256,87 MB oldu. Occlusion bake, Windows build veya VDS değişikliği yapılmadı.

Dört geçerli koşu: 1920×1080 pencereli, taban ölçek 0,5; dört araçla başlanır, harvester ve ayna açık; yerel araç elenmişken/menüde örnek alınmaz; her koşu 60 aktif yarış saniyesidir. Enkaz test bayrağı kapalıdır. Profiller API çiftinde aynıdır. Gerçek GPU/API/çözünürlük kontrol edilir. Her koşunun JSON'u [ölçüm tablosunda](Olcumler.md) bağlantılıdır.

| GPU | Kalite | API | Kare p95 ms | Kare p99 ms | CPU ana p95 ms | GPU p95 ms |
|---|---|---|---:|---:|---:|---:|
| Intel Iris Xe | Düşük | OpenGLCore | 16.78 | 16.83 | 5.66 | desteklenmiyor |
| Intel Iris Xe | Düşük | Vulkan | 16.78 | 16.82 | 5.60 | 2.75 |
| RTX 3060 | Yüksek | OpenGLCore | 3.20 | 7.26 | 3.19 | desteklenmiyor |
| RTX 3060 | Yüksek | Vulkan | 2.31 | 7.49 | 1.96 | 0.39 |

Bu makinede Vulkan RTX p95'te daha iyi, Intel'de 60 FPS sınırı nedeniyle eşdeğerdir. **Linux sırası Vulkan → OpenGLCore** olarak açıkça kaydedildi. RTX p99 Vulkan'da biraz daha yüksek; bütün yüzdeliklerde üstünlük iddia edilmez. Yarışlar birebir kaydedilmiş aynı rota değildir; yaşayan araç dağılımları JSON'dadır. Sonuç başka sürücü/makine için garanti değildir. OpenGL GPU süresi desteklenmez; Vulkan'da gerçek GPU ölçümü alınabildi.

İlk RTX OpenGL koşusu pencere 1910×1027'ye düştüğü için reddedildi ve karşılaştırmaya alınmadı: [reddedilen koşu kaydı](sonuclar/p10-reddedilen-glcore.json). `p10-nvidia-glcore-final` tekrarı 1920×1080'de geçti. Ölçümler çözünürlük kontrolü olmadan başarı sayılmaz.

Düşük profil 60 FPS ile sınırlandığından Intel'in 16,78 ms p95'i, öneri 16,7 ms eşiğini az farkla aşar; hedef tümüyle tutturuldu diye raporlanmaz. RTX Yüksek p95 <7 ms hedefi iki API'de de sağlandı. GPU süresinden veya FPS sınırından uydurulmuş hız kazanımı çıkarılmadı.

Tekrar koşmak: `python3 tools/run_race_checks.py --mode perf --label yeni-etiket --gpu intel --api vulkan --seconds 60` (diğer kart için nvidia, diğer API için glcore). Vulkan'da runner yerel ICD dosyası varsa seçilen GPU'yu zorlar; bu iki GPU'lu makinede varsayılan Vulkan otomatik olarak RTX'i seçti. Online ve performans koşularının tercihleri Builds altında ayrı XDG klasörlerindedir; kişisel kayıtlar kullanılmaz.

API sırasını tekrar kuran menüler: `Harvester/Build/Linux Vulkan Öncelikli`, `Harvester/Build/Linux OpenGL Öncelikli`. Son development build 0 hata / 0 uyarı. Son gerçek Relay testi (iki yerel player, VDS Relay): [geçti](p10-son-online.json); yarış başladı/bitti, iki taraf bağlantı açık Lobby oda ekranına döndü, NetworkConfig mismatch ve Exception yok.

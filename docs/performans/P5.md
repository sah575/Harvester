# P5 — harvester görsel LOD

Kaynak ~116,7 bin üçgen yerine LOD0 **11.721**, LOD1 **4.404** üçgendir. LODGroup CrossFade/dither kullanır; URP profillerinde LOD crossfade zaten açıktır. Dört tekerlek, tabla ve döner tamburun altı dönüşümü ayrı görsel LOD'a kopyalanır. Yapay zekâ ve fizik özgün hiyerarşide kalır.

Pivot/eksen güvenliği için Unity kaynak mesh'leri yerel koordinatlarıyla dışa aktarılır; Blender Decimate yeni FBX üretir. FBX'teki kalibrasyon tetrahedronu eksen/birim dönüşümünü tersine çevirir; üretilen Unity mesh asset'leri özgün transformlara bağlanır. Kaynak FBX ve görsel prefab değiştirilmez. Küçük kabin/cam/ayna parçaları özgün geometri olarak korunur. Blender'da UV sınırlarında çoğaltılmış köşeler birleştirilir ve yüzey yönleri tutarlı yapılır. İlk görsel deneme bu yüzden reddedilip yeniden üretildi.

Tekrar üretim:

1. `Harvester/LOD/Harvester Kaynağını Dışa Aktar` → `/tmp/harvester-lod-source.json`.
2. `blender --background --python BlenderSources/harvester/uretim_lod.py -- /tmp/harvester-lod-source.json Assets/Models/Harvester/LOD/Harvester_LOD.fbx`.
3. `Harvester/LOD/Harvester LOD Meshlerini Üret`, ardından `Harvester/Rebuild Harvester AI`.

Fizik öncesi/sonrası karşılaştırması [aynı değerleri](harvester-lod-fizik.txt) verdi: collider merkezleri/boyutları, dört tekerlek yarıçapı ve groundProbe, tabla özgün genişlik/ölçek parametreleri, ağ hash'i **2234473262** değişmedi. Harvester davranış dosyaları ve boyutu değişmedi. Altı animasyon eşlemesi Play mode'da doğrulandı; eksik script/referans denetimi geçti. Linux build 0 hata / 0 uyarı.

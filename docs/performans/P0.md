# P0 — ölçüm altyapısı

PerfProbe yalnız development/editör ve açık `-perfProbe <sn> -perfLabel <ad>` isteğiyle kurulur. `-perfOutput <klasör>` verilmezse persistentDataPath/perf kullanılır. Aktif yarıştan 60 saniye örnek biriktirir; 3 bot + host, harvester ve ayna senaryosu tools/run_race_checks.py ile tekrarlanır. Menü/yükleme ve yerel oyuncunun elenmesi dışarıda kalır. Yarış davranışına müdahale edilmez, normal turlar tekrar başlar. CSV, p50/p95/p99 JSON'u ve [Perf] özeti üretilir.

FrameTimingManager CPU toplam/ana/render/present bekleme süreleri çalışıyor. Linux OpenGLCore iki GPU'da da GPU zamanını 0 döndürüyor: GPU ms bu yüzden -1/geçerli örnek 0 olarak raporlandı. Desteklenmeyen Render Thread profiler işaretçisinin yerine gerçek FrameTimingManager render süresi mevcut. GPU zamanı CPU/present süresinden tahmin edilmedi. Farklı API P10'da ayrıca ölçülecek.

Intel Iris Xe ve RTX 3060 gerçek cihaz adlarıyla, 1920×1080 pencerede doğrulandı. Her iki koşu 60 aktif saniyeyi tamamladı, karelerin yaklaşık %94'ünde dört araç da canlıydı. Başlangıç gerçek renderScale=1.0; P1 hatasının etkisi henüz düzeltilmedi. [Ölçümler](Olcumler.md).

Tekrar:

```
python3 tools/run_race_checks.py --mode perf --label p0-intel --seconds 60 --gpu intel
python3 tools/run_race_checks.py --mode perf --label p0-nvidia --seconds 60 --gpu nvidia
python3 tools/summarize_perf.py p0-intel p0-nvidia
```

Koşular ayrı XDG_CONFIG_HOME dizinleri kullanır; oyuncu tercihlerinden etkilenmez. Ayna ölçüm sırasında açık istenir ve yalnız gerçekten gösterildiği kareler alınır. GPU/çözünürlük beklentisi doğrulanır. Ham CSV: Builds/reports/<etiket>/<etiket>.csv. Sayaç örnekleri bellekte sabit kapasiteli listede tutulup ölçüm sonunda yazılır; kare başına ölçüm metni/CSV tahsisi yapılmaz. Unity derlemesi ve Linux Mono development build: 0 hata, 0 uyarı.

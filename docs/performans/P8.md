# P8 — HUD bellek tahsisi

RaceHUD'un sonuç/izleyici stilleri çözünürlük değişiminde bir kez kurulur. Sabit Rect/Label kullanan göstergeler yalnız Repaint olayında çizilir. Süre/sıra, hız ve harvester mesafe metinleri gösterilen değer değişince yenilenir. Harvester rengi her karede HTML/Regex metni üretmek yerine GUIStyle rengiyle verilir; renk etiketi olmayan gölge metni Regex'e girmez. Ağ göstergesinin StringBuilder'ı, normal/gölge metinleri önbelleklidir; metin 0,25 saniyede bir yenilenir. Ping/girdi/ağ mesajı sıklığı değişmedi, F3 tercihi yenilemeyi öne alır.

Iris Xe / Düşük / 1080p / 60 aktif saniye: P6 → P8 GC p50 **8.202 → 2.692 B/kare (%67,2 azalma)**; p99 **19.822 → 14.510 B/kare**. CPU ana p95 **5,43 → 5,22 ms**, render p95 **1,22 → 1,16 ms**, kare p95 16,76 → 16,76 ms (60 FPS sınırı). Draw p50 123 ve SetPass 24 aynı. Üç bot/host/harvester/ayna ve normal enkaz seçeneği JSON ile doğrulandı. P7 havuzunun yarış tüketicisi yoktur, bu fark HUD değişikliğidir. Derleme/Console hatasız; Linux development build başarılı. Son uçtan uca testte geri sayım, uyarı, elenme/sonuç ve lobi dönüşü de kontrol edilecektir.
